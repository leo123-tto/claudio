# 开发进度

> 公开仓的进度只记「现在能做什么」和重要变化；细节看提交记录和 PR。

## 从 macOS App 到网页版

- 早期版本是 macOS Tauri App：打开后自动起内置 Node 和网易云服务，关窗清理子进程。
- 现在只有网页版：服务跑在一台常开的机器上（`deploy/box/` 有容器样例），电脑和手机浏览器打开同一个地址就能听。桌面 App 于 2026-11-23 去掉。
- 个人版和公用版用同一份网页 `web/`，服务端 `GET /api/mode` 告诉网页是哪一版、露哪些按钮。
- ChatGPT、Grok、Ornith、Agent2API 等大脑通道已下线，旧设置读进来自动迁到本地服务。

## 当前能力

- 大脑三选一：本地 OpenAI 兼容服务（默认）/ Claude Code CLI / DeepSeek 官方 API；失败明确报错，不自动切换。
- 后台常备两期节目，没备好先放垫场歌（收藏 + 最近放过），不冷场；换口味后旧节目作废。
- 语音：自建 Fish S2-Pro（默认，可经 ssh 隧道 + gpuctl 按需拉起）/ Fish Audio 云端；语音不在时只放歌，回来后自动恢复。口播边合成边播放。
- 推荐以收藏为风格锚点，结合最近播放、跳过、收藏、禁播和长期记忆；点了曲风时要有网易云曲风证据才放。
- 此刻场景：按工作日 / 周末和时段默认，听众说「我在上班」之类会临时改场景；个人作息补充写本机 `.env`。
- 网页播放器：两路交叉淡入 + 口播、歌词平滑滚动、沉浸歌词、睡眠定时、多设备接力（一台开始响，别的自动停）；适配手机竖屏 / 横屏 / 折叠屏。
- 语音点歌：短录音转写后走现有的暂停 / 换歌 / 点歌。
- 播放设备：macOS 上可把 Claudio 单独送到某个 AirPlay 输出，不改系统默认输出；房间别名。
- 公用版（`CLAUDIO_MODE=public`）：邀请制多人版，每人绑定自己的网易云账号，cookie 和临时记忆加密存储。
- 网易云限流保护：后台搜索排队、按接口冷却；同一出口的多个实例共用搜索名额。

## 验证基线

- `npm test`：Node 单测覆盖模型契约、意图分流、推荐过滤、节目缓冲、语音通道、网易云限流、设置与密钥隔离、多设备接力、公用版等。CI 在每个 PR 上跑。
