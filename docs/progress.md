# 开发进度

## 当前能力

- macOS Tauri App：直接打开后自动启动内置 Node 与网易云音乐服务，关闭窗口时清理全部子进程。
- ChatGPT、Grok、Claude、DeepSeek 四种大模型通道可在设置中切换，默认使用兼顾速度和质量的 Luna 低推理模式。
- Grok 走 SuperGrok / X Premium+ 订阅：设置里弹出系统浏览器验证，登录态保存在本机，不消耗 xAI API Key。
- Fish Audio 流式语音；失败时明确提示，不自动切换到 macOS 本地语音。
- 对话、推荐和播放器控制意图分流；聊天不会强制换歌，暂停、下一首和音量等指令直接控制播放器。
- AirPlay 系统设备选择器，可投放到支持 AirPlay 的音箱。
- 推荐系统以收藏歌曲为风格锚点，结合近期播放、跳过、收藏、不喜欢和稳定记忆挖掘相邻小众音乐。
- 设置中可粘贴网易云歌单链接或 ID，合并去重到每台电脑自己的本地口味曲库。
- App 包只带空白用户模板，个人数据、密钥、日志和缓存不进入源码或安装包。

## 验证基线

- Node 测试覆盖模型契约、Grok 订阅登录落盘、意图判断、推荐过滤、画像权重、歌单导入、密钥隔离、AirPlay 和父进程监控。
- Rust 测试覆盖 App 资源/数据目录隔离和首次启动初始化。
- 内置网易云服务只开放 Claudio 使用的五个只读接口。
