# 开发进度

> 公开仓的进度只记「现在能做什么」和重要变化；细节看提交记录和 PR。

## 从 macOS App 到网页版

- 早期版本是 macOS Tauri App：打开后自动起内置 Node 和网易云服务，关窗清理子进程。
- 现在只有网页版：服务跑在一台常开的机器上（`deploy/box/` 有容器样例），电脑和手机浏览器打开同一个地址就能听。桌面 App 于 2026-11-23 去掉。
- 个人版和公用版用同一份网页 `web/`，服务端 `GET /api/mode` 告诉网页是哪一版、露哪些按钮。
- ChatGPT、Grok、Ornith、Agent2API 等大脑通道已下线，旧设置读进来自动迁到本地服务。

## 当前能力

- 大脑三选一：本地 OpenAI 兼容服务（默认）/ Claude Code CLI / DeepSeek 官方 API；失败明确报错，不自动切换。
- 后台常备两期节目，没备好先放垫场歌（收藏 + 最近放过），不冷场；换口味后旧节目作废。
- 语音：自建 Fish Drama 3（默认，可经 ssh 隧道 + gpuctl 按需拉起）/ Fish Audio 云端；语音不在时只放歌，回来后自动恢复。网关支持时整段流式合成、边合成边播放；口播稿一写完就先合成，不等选歌。
- DJ 叫 Vera（产品仍叫 Claudio）：两版共用人格核心 `prompts/vera.md`，平时是有反差的老朋友，夜里是耳语守夜人，周末或说「随便放」时是策展人；个人版可在数据目录另放 `user/persona.md` 追加背景。
- 时段语气档：清晨 / 上班 / 午休 / 白天 / 傍晚 / 夜晚 / 深夜 / 驾驶，各有写法、语音导演提示和允许的演出标记（叹气、轻笑、停顿、耳语等）；页面上只显示干净文字。
- 口播频率：话多 / 适中 / 安静 / 几乎不说，设置里选，也能对 Vera 说「少说点」「今天别打扰我」；当面说话总会回。
- 推荐以收藏为风格锚点，结合最近播放、跳过、收藏、禁播和长期记忆；点了曲风时要有网易云曲风证据才放。
- 此刻场景：按工作日 / 周末和时段默认，听众说「我在上班」之类会临时改场景；个人作息补充写本机 `.env`。
- 网页播放器：两路交叉淡入 + 口播、歌词平滑滚动、沉浸歌词、睡眠定时、多设备接力（一台开始响，别的自动停）；适配手机竖屏 / 横屏 / 折叠屏。
- 语音点歌：短录音转写后走现有的暂停 / 换歌 / 点歌。
- 聊天模式（两版都有）：在输入框说话就进，歌压到背景（默认 25%，45 秒没人说话恢复，`CHAT_BED_VOLUME` / `CHAT_IDLE_SEC` 可配），Vera 接着前几句聊、默认不换歌；她自己想推的歌排在当前这首后面，听众点歌才马上换。「就听歌」退出。iPhone 上网页改不了音量：念的时候先停歌、念完原处接着放，换歌不重叠。
- 驾驶模式（两版都有）：大按键、口播只说一句、点一下说话，屏幕常亮。
- 真实音质：播放页显示实际拿到的格式和规格（如 FLAC 24bit/96kHz），拿不到就不显示。
- 版本号：`/api/mode` 带 `version`，设置 / 账号面板角落显示，方便确认改动上线没有。
- 驾驶模式：整屏三个大键 + 说话键，口播只说一句；屏幕常亮（支持时）。
- 页面显示这首歌实际拿到的音质（格式 / 位深 / 采样率 / 码率，拿不到的不显示）；设置 / 账号面板角落显示版本号（git 提交短号）。
- 播放设备：macOS 上可把 Claudio 单独送到某个 AirPlay 输出，不改系统默认输出；房间别名。
- 公用版（`CLAUDIO_MODE=public`）：邀请制多人版，每人绑定自己的网易云账号，cookie 和临时记忆加密存储。
- 好友互荐（两版都有）：好友码互加；把正在放的或最近听过的歌推荐给好友，可附一句话；对方下一批第一首就是它，Vera 报幕说是谁推荐的、念出附言。附言发出时过本地规则和大脑检查；每天有上限、可屏蔽；推荐人看得到已播和「好听」，看不到被跳过。个人版经同一台机器上的内部口接进公用版的好友圈，朋友推荐的歌不算进个人口味。
- 推荐先问再放（收自 #2，感谢 @Poy-Coder）：朋友推荐的歌报幕最后问「要听吗？」，网页开麦听 5 秒；说听就放，说不听或没听清就先存着（好友面板里点「听」找回），根本听不了（没麦克风 / 不给权限）照旧直接放。公用版用浏览器听写，个人版走短句识别。
- Vera 的笔记本：人 / 习惯 / 歌 / 事四栏长期记忆，能看、能改、能删、能标「别再提」；口播只在挂着这首歌时才提起旧事。
- 网易云限流保护：后台搜索排队、按接口冷却；同一出口的多个实例共用搜索名额。
