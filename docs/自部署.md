# 自部署指南

fork 一份，部署在你自己的机器上，自己用。

- 只想用、不想部署：去 [申请页](https://dj.ajkb.app/apply) 申请维护者运营的公开版。
- 只想在自己电脑上改代码：看 [上手指南](./上手指南.md)，那里更短。

---

## 个人版：一个人的电台

### 要准备的三样东西

| 东西 | 必须吗 | 可选项 |
|---|---|---|
| 大脑（大模型） | 必须 | 见下文「大脑」 |
| 网易云账号 | 实际上必须 | 不登录基本放不出歌；音源可用插件扩展 |
| 语音（TTS） | 可以不要 | 不配就只放歌，口播出文字 |

再加一台常开的机器（Linux / macOS 都行，内存 1 GB 以上就够）和 Node.js 20+。

### 大脑

三选一，在网页右上角 ⚙ 里切；一家失败会直接报错，不会自动换到另一家。

| 选项 | 怎么配 | 适合 |
|---|---|---|
| DeepSeek 官方 API | `.env` 填 `DEEPSEEK_API_KEY` | 最省事，按量付费，便宜 |
| 本地 OpenAI 兼容服务 | ⚙ 里填地址（如 `http://127.0.0.1:8001/v1`）和 key，或写 `.env` 的 `LOCAL_LLM_BASE_URL` / `LOCAL_LLM_API_KEY` | 自己有显卡、跑 Ollama / vLLM / LM Studio 之类 |
| Claude Code CLI | 本机装好并登录 `claude`；`.env` 可改 `CLAUDE_BIN` / `CLAUDE_MODEL` | 已有 Claude 订阅 |

默认选中的是「本地」，没有本地服务时记得在 ⚙ 里切到别的。一期节目生成几秒到一两分钟，后台会常备两期，没备好时先放垫场歌。

### 网易云

1. 起网易云 API：`npm run ncm`（默认 `:3000`；`.env` 的 `NCM_BASE` 指向它）。
2. 登录：`npm run login:ncm`，用网易云音乐 App 扫码，cookie 自动写进本机 `.env` 的 `NCM_COOKIE`。
3. 音质：`NCM_LEVEL`，`exhigh` 是 320k；无损要会员。

几个现实情况：

- VIP 歌、没版权的歌，登录了也拿不到直链。这时会跳过换一首。
- 搜得太密会被网易云限流（405「操作频繁」）。后台搜索已经排队限速（`NCM_SEARCH_GAP_MS` / `NCM_SEARCH_PER_MIN`），别再调高。
- 音源可用插件扩展：在数据目录放插件（接口见 [上手指南·音源层](./上手指南.md#音源层和插件接口)），网易云拿不到时会去插件里找。插件要自己负责合规，仓库不提供。

### 语音（TTS）

在 ⚙ 里选；失败不会自动换另一家，这期跳过口播、照常放歌。

| 选项 | 怎么配 |
|---|---|
| 不配 | 什么都不做，只放歌、口播出文字。 |
| Fish Audio 云端 | `.env` 填 `FISH_API_KEY`、`FISH_REFERENCE_ID`（音色 id），⚙ 里切到 Fish。按字符计费。 |
| 自建 Fish S2-Pro 服务 | 自己有显卡，跑 Fish 官方服务（提供 `/v1/tts`、`/v1/health`）。`.env` 填 `PC5090_TTS_BASE_URL`（服务地址）、`PC5090_TTS_VOICE`（已注册的音色）。`PC5090_TUNNEL_HOST` 留空就直连；不填 `PC5090_SSH_HOST` 就不会去远程拉起服务，你自己保证它常开。 |
| macOS `say` | 只在 Mac 上、开发时用。 |

### 部署

#### 最简单：直接跑

```bash
git clone https://github.com/<你的账号>/claudio.git && cd claudio
npm ci --omit=dev
cp .env.example .env                  # 按上面三样填
cp -r packaging/default-user user     # 口味档案：taste.md 写你的口味，favorites 可在 ⚙ 里导入网易云歌单
npm run ncm &                         # 网易云 API
npm start                             # Claudio，默认 :8080
```

长期跑可以交给 `pm2`、`systemd` 或 macOS 的 `launchd`，任选。

#### 容器：`deploy/box/`

一台 Linux 机器上跑容器：Node 22 装在宿主机、只读挂进容器；代码、数据都挂载，镜像本身只有 debian + tini。

```bash
BASE=~/stacks/claudio                      # 可用 CLAUDIO_BASE 改
git clone https://github.com/<你的账号>/claudio.git "$BASE/app"
(cd "$BASE/app" && npm ci --omit=dev)
mkdir -p "$BASE/data/cache/logs"
cp "$BASE/app/.env.example" "$BASE/data/.env"           # 按注释填；另加 HOST=127.0.0.1、PORT=8090、NCM_BASE=http://127.0.0.1:3010
cp -r "$BASE/app/packaging/default-user" "$BASE/data/user"
NODE_DIR=/path/to/node-v22 CLAUDIO_BASE="$BASE" sh "$BASE/app/deploy/box/run.sh"
```

- 容器里同时起网易云 API（只开只读接口，`:3010`）和 Claudio。数据目录 `CLAUDIO_DATA_DIR=/data`：读 `data/.env`、`data/user/`，写 `data/cache/`。
- 网易云登录：在别的机器上 `npm run login:ncm` 拿到 cookie，填进 `data/.env` 的 `NCM_COOKIE`。
- 更新：`git pull` 之后重跑 `run.sh`。

#### 对外访问

服务本身是 http。只在家里局域网用，直接 `http://<机器地址>:8080` 就行。

要在外面用、要手机上的语音按钮 / 添加到主屏幕 / 锁屏播放，套一层 HTTPS 反向代理：Caddy、nginx、Tailscale serve、Cloudflare Tunnel 任选。

**个人版没有登录**：谁能打开地址，谁就能用你的大模型额度和网易云账号。别把个人版直接暴露在公网上；对外请用只有你能进的方式（内网穿透 + 访问控制、Tailscale 之类）。

## 公用版：邀请几个朋友一起用

`CLAUDIO_MODE=public`，代码在 `server/public/`，网页和个人版是同一份 `web/`。

**要自备 hub**：进门相关的事（申请、审批、邀请链接、设备、配对码、每日次数）全交给一个外部服务 hub，本仓库不含 hub。要部署公用版，先自己实现一个满足 [hub-api.md](./hub-api.md) 接口的服务。

```bash
BASE=~/stacks/claudio-public
git clone https://github.com/<你的账号>/claudio.git "$BASE/app"
(cd "$BASE/app" && npm ci --omit=dev)
cp "$BASE/app/deploy/public/secret.env.example" "$BASE/secret.env" && chmod 600 "$BASE/secret.env"
# 填：PUBLIC_HUB_BASE / PUBLIC_HUB_KEY（hub）、PUBLIC_VAULT_KEY（openssl rand -hex 32，加密每人的网易云 cookie）、
#     PUBLIC_LLM_BASE / PUBLIC_LLM_MODEL / PUBLIC_LLM_KEY（OpenAI 兼容大脑）、PUBLIC_APPLY_ORIGINS（申请页所在站点）
NODE_DIR=/path/to/node-v22 sh "$BASE/app/deploy/public/run.sh"
```

- 只听 `127.0.0.1:8091`，对外经 HTTPS 反向代理；设备凭证是 httpOnly cookie（`PUBLIC_COOKIE_SECURE=0` 只用于本机 http 自测）。
- 启动自检：环境里出现个人版的密钥（`NCM_COOKIE`、`FISH_API_KEY`、`DEEPSEEK_API_KEY` 等）会拒绝启动，两版的配置不要混。
- 和个人版装在同一台机器、同一出口 IP 时，网易云按总数限流：个人版设 `NCM_SHARED_SERVE=127.0.0.1:8099`，公用版设 `NCM_SHARED_URL=http://127.0.0.1:8099`，搜索名额合着算。
- 申请页想加人机校验：配 Cloudflare Turnstile 的 `PUBLIC_TURNSTILE_SITEKEY` 和 secret（可放文件，见 `run.sh`）。
- 每个朋友用自己的网易云账号放歌。开放给别人用之前，先想清楚版权和平台协议的风险由谁承担。

## 隐私

- `.env`、API key、网易云 cookie、`user/`、`cache/`、日志都被 Git 忽略，只在你自己机器上。
- 自己机器的地址、主机名、作息等个人化配置一律写本机 `.env`，不要写进代码。
